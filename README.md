# Ping

A minimal native macOS ping app written in SwiftUI. 一个用 SwiftUI 编写的极简 macOS Ping 工具。

It sends real ICMP echo requests through an unprivileged datagram socket, so it needs no root and no extra permissions.

## Features / 功能

- Real ICMP ping with round-trip time, TTL and reply size per packet
- Fixed count (1–100) or continuous (∞) mode
- Adjustable packet size, TTL, timeout and send interval
- Reports "Time Exceeded" and "Unreachable" errors
- Status bar: Sent, Received, Lost, Loss %, Min / Avg / Max / StdDev
- Light, dark and system appearance
- English and 中文 interface, switchable at runtime
- Presets menu for common targets

## Requirements / 环境要求

- macOS 13 or later
- Xcode Command Line Tools (`xcode-select --install`). Full Xcode is not required.

## Build and run / 编译运行

```bash
./build_app.sh run     # build build/Ping.app and launch it
./build_app.sh build   # build only
```

The script compiles with `swiftc` directly and ad-hoc signs the bundle. On first launch of a copy downloaded from elsewhere, right-click the app and choose Open.

If your toolchain has a working SwiftPM, `swift run` also works.

## App icon / 图标

The icon is generated by code. After editing the design, regenerate it with:

```bash
swift Icon/make_icon.swift
```

## Project layout / 目录结构

| Path | Purpose |
| --- | --- |
| `Sources/Ping/ICMPPinger.swift` | ICMP socket, packet building and parsing |
| `Sources/Ping/PingViewModel.swift` | Ping loop, options, statistics |
| `Sources/Ping/ContentView.swift` | Main window |
| `Sources/Ping/StatusBar.swift` | Bottom statistics bar |
| `Sources/Ping/Language.swift`, `Appearance.swift` | Language and color scheme |
| `Icon/` | Icon generator and generated assets |
